# R3TTA

Minimal runnable code for R3-TTT (the 2026-09-23 version of the method), together with the Trump post data and the market data.
Experiment results, logs, and paper sources are not included.

## File structure

```
source_code/
├── README.md
├── data/
│   ├── posts.csv             Trump Truth Social posts (from 2022-01; union of the four US-session bands in BJT)
│   └── market_15min.csv      15-minute bars for 39 symbols (SPY, sector ETFs, single stocks, ...; from 2024-11)
├── config/
│   └── arch_sweep2.json      architecture sweep record for the MLP+BN / FT-Transformer backbones
│                             (exp_gradient_tta_lib uses it to pick the architecture)
└── code/
    ├── common_protocol_clean.py    data protocol: reads posts/market, aligns each post to the next tradable
    │                               15-minute bar, features, labels, train/val/test split, frozen GBT anchor,
    │                               bar memory
    ├── exp_clean_core.py           retrieval routing (route) and other base functions
    ├── exp_ablation_sensitivity.py evaluation tools: AUC/Brier, BarIndex, paired block bootstrap
    ├── exp_residual_20260921.py    neighbour retrieval (Retrieved) and the 0921 reference arms
    ├── exp_lib_0923.py             R3-TTT core: Fold (one deployment), all method arms and reference arms
    ├── exp_candidates_0923.py      [1] candidate screen, runs on walk-forward / validation only
    ├── exp_declare_0923.py         [2] locks the final method by rule, writes results/r3ttt_0923/protocol_0923.json
    ├── exp_final_test_0923.py      [3] the single test read (GBT / MLP+BN / FT-Transformer backbones)
    ├── exp_ablation_0923.py        [4] ablations and sensitivity
    ├── exp_new_baselines.py        neural backbone environments and the AdaNPC baseline (called by [3] and exp_lib)
    ├── exp_knn_neural_0911.py      refits the MLP+BN / FT-Transformer anchors (called by [3])
    └── exp_gradient_tta_lib.py     neural network definitions and training (torch)
```

## Data sources

| File | Content | md5 |
|---|---|---|
| `data/posts.csv` | Truth Social posts, 2022-01 onward, restricted to US-session times | a1abcc0627c2e66c29d659c7b494340c |
| `data/market_15min.csv` | 15-minute OHLCV bars, 39 symbols | 9590a5ae5558f7b752fa7dcae376ff1d |

- The code reads only three post columns: `post_id, created_at_utc, text`. The engagement counts (reblogs/favourites/replies) are a single crawl snapshot from 2026-04-10 and are future information for test rows, so the code deliberately does not read them.
- Only posts from 2024-11-06 onward are used. Split: train < 2025-10-01 ≤ validation < 2026-01-01 ≤ test < 2026-04-11.
## Running

Requirements: Python 3.10+, numpy, pandas, scikit-learn, scipy, joblib; torch for the neural backbones.
Run every script from `code/`. Paths resolve relative to the repository root. Outputs go to `results/r3ttt_0923/`, caches to `data/cache_clean/`.

```bash
cd code
python exp_candidates_0923.py --panel wf  --round 1   # see the script header for which rounds to run
python exp_candidates_0923.py --panel val --round 1
python exp_declare_0923.py                            # writes protocol_0923.json
python exp_final_test_0923.py
python exp_ablation_0923.py --panel test
```

## Known limitations

- `exp_final_test_0923.py` checks the reference arms of all three backbones against stored numbers in `results/knn_neural_0911/metrics.csv` (a provenance gate). That file is an experiment output and is not included; produce it first with `exp_knn_neural_0911.py`, or remove the check.
- `protocol_0923.json` records the sha256 of each code file, so it must be regenerated by `exp_declare_0923.py` before `exp_final_test_0923.py` and `exp_ablation_0923.py --panel test` will run.
- The data panel loads to 6,843 pre-test posts (5,277 train + 1,566 validation).
